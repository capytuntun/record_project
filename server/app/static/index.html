安裝包

產生內含設定的 Windows Agent 安裝檔（.msi），直接下載後派送到電腦上。

產生安裝包（MSI）
有效期間

逾期後此安裝包無法再用於註冊，已註冊的電腦不受影響。

可使用次數

一台電腦註冊算一次。次數用完或期間屆滿，先到者先失效。

管理密碼（選填）

設定後，在該電腦上變更 Agent 設定、清除註冊資料、以及解除安裝都需要此密碼。 密碼以 PBKDF2 雜湊寫入安裝包，明文不會儲存。 企業 IT 仍可用此密碼（msiexec /x ... UNINSTALLPWD=）或透過 GPO/MDM 正常移除；一般使用者無此密碼則無法自行移除。
