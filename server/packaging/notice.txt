螢幕測錄系統 —— 管理伺服器

這個精靈會在這台 Windows 電腦上架設「螢幕測錄系統」的管理伺服器（主控台）。按「下一步」開始。

安裝過程會自動完成：

• 建立 Python 執行環境並安裝相依套件。
• 產生隨機金鑰與自簽 TLS 憑證，讓主控台用 https:// 連線。
• 建立資料庫與最高管理員帳號，並產生一組新的管理員密碼（會在最後一頁顯示，只顯示一次）。
• 設定開機自動啟動，並（可選）在防火牆放行連接埠。
• （可選）安裝 .NET SDK 與 WiX，讓主控台可以直接產生端點 Agent 的安裝包。
• （可選）安裝 FFmpeg 以支援螢幕錄影。

需要連線網際網路：缺少的元件（Python、.NET、FFmpeg）會自動下載，過程可能需要數分鐘。請全程保持電腦開機與連線。

自簽憑證：預設產生的憑證未經公開憑證機構簽署，瀏覽器會出現安全警告，端點 Agent 也必須信任它才能連線。正式環境建議改用公司憑證（安裝後於設定檔 .env 指定）。

重新執行＝就地升級／修復：再次執行本精靈會更新程式碼，並重設管理員密碼成一組新的（完成頁會顯示，舊的登入階段會失效）；資料庫、金鑰與錄影都會保留。

安裝並使用本系統，代表你已獲公司授權部署端點監控，且使用方式符合當地法令與公司政策。如有疑問，請先洽詢法務或資安人員。
